3. HOW TO RUN THE FRONTEND (PORT 5173)
--------------------------------------------------------------------------------
Step 1: Open a terminal / command prompt.
Step 2: Navigate to the frontend directory:
        cd c:\Users\HELLO\Downloads\SmartTrip\frontend

Step 3: Start the Vite development server:
        npm run dev
        (On Windows PowerShell if execution policy is restricted: cmd /c npm run dev)

Step 4: Open your web browser and navigate to:
        http://localhost:5173

--------------------------------------------------------------------------------
Step 1: Open a second terminal / command prompt.
Step 2: Navigate to the backend directory:
        cd c:\Users\HELLO\Downloads\SmartTrip\backend

5. HOW TO CHECK & INSPECT THE MONGODB DATABASE
--------------------------------------------------------------------------------
• Database Name: smarttrip_db
• MongoDB URI:   mongodb://localhost:27017/smarttrip_db

METHOD 1: USING MONGODB COMPASS (GUI - RECOMMENDED)
---------------------------------------------------
1. Download & launch MongoDB Compass (https://www.mongodb.com/try/download/compass).
2. Enter Connection String: mongodb://localhost:27017
3. Click "Connect".
4. Select the database: smarttrip_db
5. Click on smarttrip_db to inspect the 3 core collections:
   - users    (Contains Super Admin, Admin, and Traveller accounts + isBlocked status)
   - places   (Contains attractions, hotels, restaurants, hospitals, ATMs)
   - trips    (Contains saved trip itineraries, budgets, and selected places)

METHOD 2: USING MONGODB SHELL (mongosh CLI)
-------------------------------------------
1. Open terminal and run MongoDB shell:
   mongosh "mongodb://localhost:27017"

2. Switch to the SmartTrip database:
   use smarttrip_db

3. View collections:
   show collections

4. Query records:
   db.users.find().pretty()
   db.places.find().pretty()
   db.trips.find().pretty()

5. Query specific Super Admin user:
   db.users.find({ email: "smarttrip@gmail.com" }).pretty()

METHOD 3: VERIFYING DATABASE DATA VIA LIVE REST APIs
-----------------------------------------------------
Test backend endpoints directly in browser or Postman:

• View All Users (Admin/Super Admin endpoint):
  http://localhost:8080/api/v1/admin/users

• View System Summary Stats:
  http://localhost:8080/api/v1/admin/stats

• View All System Trips:
  http://localhost:8080/api/v1/admin/trips

• View Places for Destination:
  http://localhost:8080/api/v1/places/nearby?destination=Paris

• View Demo User Saved Trips:

7. TROUBLESHOOTING & FREQUENTLY ASKED QUESTIONS
--------------------------------------------------------------------------------
Q: Why are selected places persistent across page reloads?
A: Selected places are automatically cached in browser localStorage under
   `smarttrip_selected_places_${destination}` and synced to MongoDB when you click
   "Save Trip".

Q: What happens if MongoDB is offline?
A: Spring Boot gracefully detects MongoDB availability. If MongoDB is offline,
   the system runs on runtime mock memory store without crashing.

Q: How do I test account blocking?
A: Log in as Super Admin (smarttrip@gmail.com), click "Admin Dashboard" in top nav,
   navigate to "Users", and click "Block Access". The blocked user will be rejected
   with a 403 error on their next login attempt.
